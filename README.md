# Лабораторная работа по FastAPI

## Структура проекта
- `main.py` — точка входа, подключение роутеров, настроек и логирования
- `app/config.py` — конфигурация через `pydantic-settings`
- `app/routers/items.py` — модель `Item` и эндпоинты работы с товарами (`/items`)
- `.env` — локальные переменные окружения (исключён из Git через `.gitignore`)

## Выполненные этапы
1. Настройка проекта и окружения через `uv` (`fastapi`, `pydantic`, `pydantic-settings`).
2. Реализация базовых маршрутов (`GET /`, `GET /items/{item_id}`) и проверка в `/docs`.
3. Добавление модели `Item` и эндпоинта `POST /items/`.
4. Вынос маршрутов товаров в роутер `APIRouter` (`app/routers/items.py`).
5. Подключение конфигурации через `Settings` и `.env`, эндпоинт `GET /info`.
6. Обработка ошибок (`404 HTTPException`), валидация параметров (`Path`, `Query`, `Field`) и метаданные OpenAPI.
7. Эндпоинт обновления `PUT /items/{item_id}` и проверка уникальности имени товара.
8. Настройка логирования через `logging`.
